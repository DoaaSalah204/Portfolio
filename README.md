# Doaa Salah | Portfolio

React + Vite portfolio site.

## Run locally
    npm install
    npm run dev

## Build
    npm run build

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New > Project and import the repository.
3. Vercel detects Vite. Keep the defaults (Build command `npm run build`, Output directory `dist`) and click Deploy.

## Edit content
All text, links and project details are in `src/data.js`.
Add your GitHub link to `profile.github`; the Contact row appears automatically. The CV is `public/Doaa_Salah_CV.pdf` (replace the file to update it).
Volt screenshots are in `public/images/`.
